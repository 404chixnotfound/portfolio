About

Renovating Technology.

LocationAbuja, Nigeria
FocusGame / App Development
StatusOpen to work

I’m a software developer who treats code like both a tool and a canvas. I build apps, games, and automation systems, whether they’re running on-chain, in a browser, or a software application.

My work moves across game dev, UI architecture, cloud backends, and smart contracts. But the thread that ties it all together is renovation: I take familiar systems, strip them down, and rebuild them with fewer assumptions. Sometimes that means rewriting a game mechanic. Sometimes it means redesigning a bot’s decision flow. Always it means making the thing clearer, faster, or more honest.

I’m drawn to the indie ethos | small teams, strong visions, and work that doesn’t need a marketing budget to be felt. I build things that quietly raise the bar.
